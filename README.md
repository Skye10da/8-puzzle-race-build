# 8 Puzzle Race

A real-time multiplayer 8-puzzle race using Next.js, Tailwind CSS, and Supabase Realtime Broadcast + Presence. No database tables or authentication are used.

## Environment variables

Create `.env.local` with:

```bash
NEXT_PUBLIC_SUPABASE_URL=your-supabase-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

Run with `pnpm dev`.
